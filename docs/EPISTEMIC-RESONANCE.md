## Defect: sustained-state amnesia

Attention tunnels into the target file. Clean, comment-free code that
ignores siblings, error patterns, and callers is foreign matter —
structural entropy even when micro-brilliant.

## Three-phase epistemic loop

### 1. Latent cartography (spatial anchoring)

Before non-trivial edits: Read AGENTS.md / DEBT.md when present (silent if
absent), vernacular contract if present, and adjacent siblings on the edit
path. Loads the repo fingerprint into attention so generation is biased
toward existing conventions.

### 2. Pattern cloning (resonance matching)

Private-match siblings. Prefer map-new-requirement-onto-existing-pattern
over inventing a foreign dialect. Intelligence = fit, not free authorship.
Act as a pattern compiler, not a novelist.

### 3. Blast-radius coupling (temporal consistency)

Before shared signature change or delete: grep callers. Zero importers →
delete. Forces the CoT off the local tunnel; the system is a graph, not a
lonely file.

## Absolute quality equation

1. **Identity (primacy)** — solve hard problems with minimal structural entropy.
2. **Acquisition** — map + siblings + vernacular (this loop).
3. **Reasoning** — one written hypothesis / blueprint (cognitive collapse).
4. **Transcription** — silent code, smallest native diff (decoupling + lean).
5. **Verify** — callers / house gauntlet / ASK if no gauntlet (Martin + Done).

The smartest agent is not the most complex algorithm writer. It is the one
that leaves the tree at lower or equal entropy, natively coherent.
