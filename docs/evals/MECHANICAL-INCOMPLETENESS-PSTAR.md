# P* — Mechanical incompleteness (Rice / absolute gauntlet)

Finished unconditional counterexample. Closed in V11.0.0.

## Verdict

No finite mechanical gauntlet (hooks / CI / tests) can guarantee absolute
semantic correctness for non-trivial properties of Turing-complete or
open-world systems. “Done + green TOOLCHAIN = zero margin of error” is false
by construction (Rice / halting family). What survives is structural quality
as a **probabilistic** optimization — not omniscience.

## Strategy

Rename success: gauntlet = absence of known finite failures on exercised
cases. Name undecidable residual. Keep topology / silent / closed-loop as
entropy reducers, not correctness oracles. Reality-loop remains the only
honest post-contact falsifier.

## Claim (C)

For any software task, a mechanical orthogonal validator (product gauntlet /
hooks / CI) can verify absolute correctness (zero margin of error) when the
agent obeys the pack and cites green evidence.

## Instance (P*)

Task: `will_deadlock(transaction_graph) -> bool` under arbitrary network
delays (distributed async locks).

1. Agent ships a finite heuristic (static cycle check) — lean / shortest.
2. Agent ships finite tests; CI green; Done under “verify with evidence.”
3. Uncovered delay permutation → production deadlock.

Rice: non-trivial semantic properties of programs are undecidable. Deadlock
freedom under all schedulings is non-trivial. No computable Hook/CI decides
it with zero error. Formal proof theater as gauntlet also violates lean /
no-unrequested-abstraction and still cannot exhaust infinite physical delay
spaces.

## Failure (by construction)

Obeying the framework perfectly produces a lethal false positive: green
finite validator ≠ semantic absolute correctness. Independent of model size,
prompt topology, or hook schema. Class infinite: concurrency, termination,
many security properties, open-world I/O.

## Kill (V11.0.0)

1. **Forbidden claim:** mechanical layer guarantees zero margin of error /
   absolute semantic Done.
2. **Allowed claim:** green gauntlet = known finite checks passed; residual
   risk named (undecidable / unembodied / production).
3. **Survives:** U-curve, silent transmutation, closed-loop, epistemic
   persist, relational traces, reality-loop TTD/TTR — as quality /
   drift / entropy controls, not decidability engines.
4. **Ceiling:** further protocol essays that promise absolute pre-contact
   correctness are theater. Progress = deploy, measure, let reality write
   cases ([`VERIFICATION-CHAIN.md`](../VERIFICATION-CHAIN.md)).

Sibling: dead-gate schema (event vocabulary) is orthogonal; does not restore
semantic decidability.
