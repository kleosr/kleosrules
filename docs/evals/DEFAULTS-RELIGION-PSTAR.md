# P* — Defaults vs religion (craft layer)

Finished unconditional counterexample. Closed in V10.1.6.

## Verdict

Craft declared universal “Defaults, not religion” while also declaring
non-overridable floors (NO prose comments + never fight deny + pass what
may + off only when user says stop). Same-layer contradiction; V10.1 could
not consistently resolve both sides of an unqualified universal D.

## Claim (C)

All craft rules are soft defaults overridable by agent “why” when context
wins, and the craft layer simultaneously contains non-overridable rules.

## Instance (P*)

1. `agent.mdc`: “Defaults, not religion: override with one line of why…”
2. Same layer: NO prose comments (exceptions only machine directives);
   never fight a deny; Shell bypass forbidden; pass what may companions;
   ponytail/lean-code off only on user stop.

| Branch | Violates |
|--------|----------|
| Treat floors as defaults | Agent why / context override — blocked by gate + never fight |
| Treat floors as religion | Universal “Defaults, not religion” false |

## Failure (by construction)

Textual + mechanical: promised overrideability; tools deny the write; fighting
deny and Shell bypass forbidden. Exists every session without repo-specific
TOOLCHAIN.

## Kill (V10.1.6)

Scope Defaults to soft craft taste only (not MUST-NEVER, not live gates,
not pass-what-may load, not never-fight-deny). Mark NO prose comments as
roof-backed. User stop phrases remain the only off-switch for ponytail modes.

## Operational reading (V10.1.7)

The seam persuasion↔force is intentional engineering, not a leftover bug.
See `docs/AGENTIAL-CONTROL.md`. Soft agency on taste + mechanical correction
on roofs; do not re-label roofs as soft Defaults.
