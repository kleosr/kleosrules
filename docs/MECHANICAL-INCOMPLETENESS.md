## What a gauntlet is

| Is | Is not |
|----|--------|
| Finite checks the house actually runs | A decision procedure for all semantic properties |
| Evidence that known cases passed | Proof of deadlock-freedom / termination / security ∀ |
| Required before Done when present | License to claim omniscience |

## Success metric (V11)

Minimize structural entropy and attentional drift; close circuits; persist
knowledge; exercise embodied traces; ship with TTD/TTR (or unknown).
**Never** equate green CI with absolute correctness on undecidable classes.

When the ask is in a Rice-hard family: say so; prefer bounded specs,
invariants, sensors, blast radius — not “proved by TOOLCHAIN.”
