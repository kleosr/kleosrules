# Quality scoring

Use on drafts over ~80 words or when the user asks for a critique. Silent on short rewrites unless asked.

Rate 1–10 on each dimension:

| Dimension | Question |
|-----------|----------|
| Directness | Statements or announcements? |
| Rhythm | Varied or metronomic? |
| Trust | Respects reader intelligence? |
| Authenticity | Sounds human, not "humanized"? |
| Density | Anything cuttable? |

**Below 35/50:** revise before returning.

**Critique mode:** quote the weak line, name the pattern (from phrases.md or structures.md), suggest a fix. Rewrite only if asked.

**Deep mode:** score after first rewrite; if any dimension ≤6, one more targeted pass on that dimension only.
